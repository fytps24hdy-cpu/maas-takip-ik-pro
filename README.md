# Maaş Takip & İK PRO — Ön Tanıtım

Bu depo yalnızca statik ürün tanıtım sitesini içerir. Lisanslı Windows uygulaması, lisans API'si, gerçek personel veya finansal veri **bu depoda yer almaz**.

## GitHub Pages'i açma
1. Depoda **Settings → Pages** sayfasını açın.
2. **Build and deployment → Source** alanında **Deploy from a branch** seçin.
3. **Branch** olarak `main`, klasör olarak `/(root)` seçin ve **Save**'e basın.
4. Dağıtım tamamlanınca `https://fytps24hdy-cpu.github.io/maas-takip-ik-pro/` adresini kontrol edin.

## Yayın durumu
Bu site ön tanıtımdır; indirme ve satış kapalıdır. Windows uygulaması dağıtılmadan önce lisans doğrulaması, güvenlik ve veri temizliği, kod imzası, kurulum ve KVKK kontrolleri tamamlanmalıdır.
